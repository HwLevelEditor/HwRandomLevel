How this works

A GitHub Action periodically pulls live levels from Totaljerkface (newest / most-played / top-rated) and saves them into data/levels.json on this repo — including publish date and play count. Filters narrow that pool in your browser; the button only rolls from matches, so you shouldn’t hit deleted IDs.

Opening a pick uses Steam’s launch param: steam://run/4705510//?level_id=…

Your browser may ask permission the first time — allow it. Prefer playing in the browser instead? Use the web version. The pool isn’t every level ever made — it’s a large snapshot of levels that existed when it was last refreshed.
