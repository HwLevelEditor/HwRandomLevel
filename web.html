How this works

Same known working level pool as the Steam page. Filters narrow it in your browser; the button only rolls from matches, so you shouldn’t hit deleted IDs.

Opening a pick uses the website URL: https://totaljerkface.com/happy_wheels.tjf?level_id=…

That loads the level in the browser game on totaljerkface.com. Want Steam instead? Use the Steam version.
